## 2. Описание датасета
Используется встроенный датасет `diamonds` из библиотеки `seaborn`. Датасет содержит информацию о характеристиках 53 940 алмазов и включает следующие столбцы:

| Столбец    | Тип        | Описание                                                                 |
|------------|------------|--------------------------------------------------------------------------|
| carat      | float64    | Вес алмаза в каратах                                                      |
| cut        | category   | Качество огранки (Fair, Good, Very Good, Premium, Ideal)                  |
| color      | category   | Цвет алмаза (от D – наилучший, до J – наихудший)                          |
| clarity    | category   | Прозрачность (от I1 – наихудшая, до IF – наилучшая)                       |
| depth      | float64    | Отношение высоты к среднему диаметру в процентах                          |
| table      | float64    | Ширина верхней площадки относительно самого широкого места в процентах    |
| price      | int64      | Цена алмаза в долларах США                                                 |
| x, y, z    | float64    | Длина, ширина и высота алмаза в миллиметрах                               |

Датасет содержит как числовые (`carat`, `depth`, `table`, `price`, `x`, `y`, `z`), так и категориальные (`cut`, `color`, `clarity`) переменные, что позволяет провести полный разведочный анализ.

Вывод топ-10 самых дорогих групп.

### 4.11. Анализ выбросов (IQR)
python
for col in num_cols:
    Q1 = df[col].quantile(0.25)
    Q3 = df[col].quantile(0.75)
    IQR = Q3 - Q1
    outliers = df[(df[col] < Q1 - 1.5*IQR) | (df[col] > Q3 + 1.5*IQR)]
    print(f"{col}: {len(outliers)} выбросов ({(len(outliers)/len(df))*100:.2f}%)")
Количественная оценка выбросов по каждому числовому признаку методом межквартильного размаха.

Выбросы присутствуют во всех числовых признаках, особенно в цене и весе, что объясняется наличием очень крупных и дорогих камней.

Анализ позволил выявить ключевые закономерности в данных, которые могут быть использованы для дальнейшего построения прогнозных моделей стоимости алмазов.
